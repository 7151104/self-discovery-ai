# Ответы-доборы демо-человека на платные срезы

Закрытые ответы лестницы и полного банка, открытые `О1`–`О3` — в
`examples/demo-person-answers.md`. Профиль после лестницы считается движком, не
на глаз: те же ответы, что `DEMO_ANSWERS` / `demoProfile()` в тестах. Сюжет
ступени 4, без которого прикладные пороги не берутся: «берёт на себя больше, чем
выносит, и бросает у финиша».

Ответы ниже не противоречат лестнице: остановка до показа, вход по чужому сроку,
ускорение под нагрузкой, удар в «не воспринимают всерьёз». Закрытые варианты
совпадают с наборами, на которых движок уже берёт порог; открытые заменяют
заглушки длины на речь этого человека.

`slice_decision_moment` применяется к профилю **после** добора `slice_decisions`:
иначе способ решать пуст, и порог развилки не берётся.

Разбор открытых этой развилки, который движок сам не читает:

## findings slice_decision_moment

```json
{
  "safeTopic": true,
  "flags": ["already_chosen"],
  "codes": ["unknowable_gap"]
}
```

Добор полной карты — остаток банка из `examples/demo-person-answers.md` (вопросы,
которых нет на лестнице) плюс `О2` и `О3`. Отдельной таблицы здесь нет: второй
набор тех же ответов разъехался бы с файлом банка. Сюжет и задача периода для
порога карты — синтез открытых, как в тестах банка: круг «тащит один и бросает у
финиша», задача — выход в видимость.

Формат блока: JSON, ключи — идентификаторы вопросов среза.
