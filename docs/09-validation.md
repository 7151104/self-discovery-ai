# 09. Валидация и качество

## Ручной прогон (до кода)

**Инструменты:** Google Form + LLM + PDF/страница  
**Объём:** 30 человек минимум, 50 оптимально  
**Стоимость:** 0 ₽

### Процесс

1. Форма с вопросами из `content/questions-ladder.md` (или full bank)
2. Скоринг по `content/scoring-rules.md`
3. Ступени 1–3: lookup текстов
4. Ступень 4 / полный: LLM по промптам
5. Оформление по шаблону `docs/06-report-structure.md`
6. Фиксация реакций по памятке ниже

---

## Памятка наблюдений (на каждого человека)

| # | Что фиксировать |
|---|-----------------|
| 1 | Первая реакция — **дословно** |
| 2 | Удивление («откуда знаешь») — да/нет |
| 3 | С чем **не согласился** — конкретные пункты |
| 4 | Переслал ли **сам** (без просьбы) |
| 5 | Попросил разбор для другого |
| 6 | Уточняющий вопрос по содержанию |
| 7 | Вернулся через несколько дней |

**Не спрашивать:** «понравилось?» — вежливость = мусор.

---

## Целевые метрики (30 человек)

| Метрика | Порог «идём дальше» | Порог «переделываем ядро» |
|---------|---------------------|---------------------------|
| Удивление | ≥ 10/30 (33%) | < 3/30 |
| Пересыл / «сделай моему» | ≥ 6/30 (20%) | 0 |
| Несогласие | ≤ 2 пункта/разбор в среднем | > 4 пункта |
| Оплата 2-го среза | ≥ 1 из 30 | 0 при сильном удивлении |

---

## Чеклист качества текста

Перед выдачей любого разбора:

- [ ] Первая фраза точная и небанальная?
- [ ] Каждое утверждение проверяемо?
- [ ] Ни одно не подходит половине людей?
- [ ] Регистры = confidence?
- [ ] Напряжение — сильнейший раздел?
- [ ] Сцены с деталями, не описания черт?
- [ ] Нет методик, запрещённых слов?
- [ ] Действия невозможны для другого профиля?
- [ ] Нет лести?
- [ ] Эффект «откуда знаешь», не «красиво написано»?

---

## Калибровка контента

- Тексты ветвей ступеней 1–3: ожидается **10–15% переписать** по живым реакциям
- Вопросы с высоким несогласием → перефразировать или заменить
- Узлы с низким узнаванием → проверить пороги в scoring

## Фаза A — 7 дней Сигналов (до кода)

После бесплатной лестницы: 7 сообщений по банку, вечером «было / не было / мимо», в день 7 — сводка + одна дверь.

Делать на тех же 30 людях или на подвыборке ≥10, кто дошёл до ступени 4.

| Метрика | Порог «механика живая» | Порог «не гороскоп и не надо» |
|---------|------------------------|------------------------------|
| Открыл ≥5 из 7 дней | ≥ 40% выборки | < 15% |
| Хотя бы 3 линзы «про меня» | ≥ 50% открывших | «красиво, ни про что» |
| Сам поделился карточкой | ≥ 1 из 10 | 0 при сильном узнавании |
| Спросил «почему так» / открыл дверь после сводки | ≥ 1 из 10 | 0 |
| Просил «что меня сегодня ждёт» | фиксировать; не подстраивать продукт | если это *главный* запрос — линза плохо объяснена |

Не спрашивать «понравилось?». Фиксировать дословно первую реакцию на день 1 и на сводку.

Полные правила: `docs/11-daily-ritual-and-social.md`.
