# Промпт: Сигнал и недельная сводка

Ежедневная линза — **не отсюда**. Она из `content/daily-signal-bank.md`.  
Сюда LLM только если: недельная сводка, подпись к артефакту, редкий оверлей открытого текста на готовый шаблон.

Сборка полного разбора по-прежнему `prompts/full-report-assembler.md`. Этот файл её не дублирует и не заменяет.

---

## Когда вызывать

| Задача | LLM? | Вход | Выход |
|--------|------|------|--------|
| Линза дня | Нет | банк | строка банка |
| Микро дня | Нет | банк | строка банка |
| Подпись к карточке / сторис | Да, короткий | `share_line` + имя + запрет уязвимости | 1–3 строки + 4 строки скрипта рилса |
| Сводка 7 дней | Да | 7 × (id, scene, ответ микро) + dominant_node + offer | 120–180 слов + одна дверь |
| Оверлей открытого О1/О3 на линзу | Да, осторожно | шаблон линзы + цитата пользователя ≤ 20 слов | линза с одной его формулировкой |

Не вызывать LLM, если не хватает подтверждений: тогда сводка = шаблон из банка без украшения.

---

## Система (все вызовы)

Ты собираешь текст для человека по **координатам и наблюдениям**, не по методикам и не по дате.

Запрещено:

- гороскоп, прогноз событий и сроков, удача, вселенная
- предназначение, энергия, миссия, вибрации, карма
- названия MBTI, Human Design, астрологии, эннеаграммы
- диагнозы, психиатрические термины
- Barnum: подходит половине, нельзя опровергнуть, комплимент без механизма
- витрина продуктов
- советы, одинаковые для другого узла
- вынос сырой уязвимости (coord 8) в шаринг
- пересказ полного отчёта другими словами
- утешение в финале сводки

Регистры: high → утверждение; medium → вероятность + признак; low → вопрос.  
Наблюдение «мимо» — данные, не спор.

Кризис (смерть, самоповреждение, безвыходность, насилие): не интерпретировать, короткий бережный текст + контакты. Не выдавать сводку и не собирать скрипт рилса.

## Сводка недели

### Вход

```
name
dominant_node
days: [{ day, signal_id, scene, family, share_line, micro_answer: yes|no|miss|did|skip }]
confirmed_count
miss_count
next_offer: { id, title, n_questions, topic }
```

### Задача

1. Первая фраза — факт недели, не портрет заново.
2. Один механизм (узел), не список черт.
3. Отдельно: что подтвердилось / что было мимо.
4. Одна конкретная сцена из дней `yes`/`did` — деталь, не абстракция.
5. Обрыв: чего не знаешь + одна дверь. Без решения (решение в платном срезе).
6. 120–180 слов. Тон как `examples/demo-report-output.md`.

### Каркас

```
[Факт: n из 7, k подтверждений узла]
[Механизм одной точной формулировкой]
[Сцена-деталь]
[Мимо — граница, не отмена]
[Чего не знаю → одно предложение среза]
```

## Подпись и скрипт рилса

### Вход

```
name
share_line
mode: self | feed
allow_face: bool
```

### Выход

**caption** (1–3 строки, от первого лица, можно запостить как есть):

```
[share_line чуть развёрнуто]
Не гороскоп. Разбор, который собирается с ответов.
```

**reel_15** (ровно 4 кадра по ~3 сек, текст на экране, без лица бренда):

1. Крючок (вопрос или удар)
2. Механизм
3. Признак
4. Тихий выход: «сегодняшняя страница» / без «подписывайся»

Если `mode=self` — про себя. Если `feed` — «я заметил у себя паттерн» (учитель из своего, не эксперт поверх чужих жизней).  
Не обещать «разберём твою судьбу». Не звать в чат.

---

## Оверлей открытого текста

Можно вставить **одну** короткую цитату человека в готовую линзу, если она подтверждает узел.  
Нельзя на её основании добавить новую черту.  
Нельзя переписать линзу в новый отчёт.

## Чеклист перед выдачей

- [ ] Первая фраза — факт или механизм, не лесть
- [ ] Есть признак несогласия
- [ ] Не подходит другому узлу без правки
- [ ] Нет методик и запрещённых слов
- [ ] Шаринг без сырой уязвимости
- [ ] Одна дверь, не витрина
- [ ] Не пересказ вчерашней линзы
