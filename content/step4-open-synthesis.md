# Ступень 4 — LLM-синтез (открытый вопрос)

**Только LLM.** Вход: profile + dominant_node + открытый ответ L12 (О1).

Собирает **финал лестницы** — тип отчёта `финал_лестницы`, 250–350 слов, три абзаца.
Не путать с полным бесплатным разбором (`бесплатный_полный`, 900–1200 слов по каркасу из
семи частей): тот собирается `prompts/full-report-assembler.md` в сценарии без лестницы.

---

## Промпт

```text
На входе:
1) Профиль координат (JSON или таблица)
2) ID и текст показанного узла (ступень 3)
3) Тексты блоков ступеней 1–2 (уже показанные пользователю)
4) Открытый ответ на вопрос: «Что в твоей жизни повторяется из раза в раз, хотя тебе это не нравится?»

Напиши финал лестницы — заключительный блок бесплатной лестницы. Тип отчёта: финал_лестницы.

ОБЪЁМ: 250–350 слов, 3 абзаца, обращение на «ты».

АБЗАЦ 1 — Сюжет
Назови повторяющийся сюжет его собственными словами. Минимум одна фраза из ответа — дословно.

АБЗАЦ 2 — Механизм круга
Соедини сюжет с механизмом из ступеней 1–3 и узлом. Покажи: с чего начинается → где ломается → почему возвращается. Это объяснение, которого не было раньше.

АБЗАЦ 3 — Обрыв
Назови 2–3 вещи, которые остались неизвестны. Без советов. Без утешения. Последняя фраза — точная и без выхода.

ЗАПРЕЩЕНО:
- диагнозы, медицина, предсказания
- предназначение, энергия, миссия, вибрации
- названия методик и типологий
- Barnum, лесть
- советы и «что делать»

РЕГИСТРЫ: только по confidence координат.

КРИЗИС в открытом ответе → не писать блок, выдать кризисный текст (см. prompts/full-report-assembler.md).

Выведи только текст блока. Заголовок: «Твой повторяющийся сюжет»
```

## Сразу после блока — платное предложение (не LLM, шаблон)

По `dominant_node` из step3:

```
[ИМЯ], я вижу, откуда замыкается этот круг — но не откуда он пошёл.

Чтобы разобрать, где этот механизм включился впервые и что с ним делать конкретно в твоей ситуации, мне нужно ещё [N] вопросов про [ТЕМА].

[Кнопка: Открыть — [ЦЕНА] ₽]
```

Подстановки — не литералы: число вопросов и цена у каждого среза свои.

| Плейсхолдер | Откуда | Поле движка |
|-------------|--------|-------------|
| `[ИМЯ]` | ступень 0 | `card.name` |
| `[N]` | колонка «Вопросов» в `content/slices/README.md` | `offer.questionCount` |
| `[ТЕМА]` | срез по `dominant_node`, см. `step3-contradictions.md` → paid_offer | `offer.slice` |
| `[ЦЕНА]` | колонка «Цена ₽» в `content/slices/README.md` | `offer.price` |

Срез выбирает `engine/src/offers.ts`, он же отдаёт эти значения наружу. Захардкоженное
число вопросов в шаблоне разъедется с контентом при первой же правке добора.
