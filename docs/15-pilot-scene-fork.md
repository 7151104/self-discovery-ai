# Пилот: одна гипотеза — «Развилка перед сценой»

Статус: **запускаем только это.** Остальные идеи (ежедневный текст, колода, второй человек, зеркало) — в заморозке до результатов пилота.

---

## Одна фраза, что мы тестируем

Человек один раз проходит разбор и узнаёт свой **узел**.  
Потом, когда в жизни назревает **конкретная сцена** (показ, разговор, решение, своё дело), он пишет нам — и получает **развилку на 30 секунд**: как он обычно ломается здесь + один вопрос. Не гороскоп. Не «страница дня». Не эссе.

**Зачем возвращаться:** не каждое утро. Когда снова случится сцена из списка.

---

## Почему выбрали именно это

| Критерий | Развилка перед сценой |
|----------|------------------------|
| Есть ли уже в продукте | Да: лестница, узел, срез, селектор |
| Нужен ли код | Нет: форма + Telegram + банк |
| Понятно ли человеку, зачем писать | Да: «завтра показ» — конкретно |
| Понятно ли тебе, о чём говорить с людьми | Да: одно предложение оффера |
| Риск «как гороскоп» | Низкий: привязка к его событию, не к дате |
| Путь к 590 ₽ | После 2+ развилок: «ты сам поймал узел — разберём откуда» |

---

## Что человек получает (весь продукт пилота)

1. **Разбор** (бесплатно, один раз) — как в `docs/09-validation.md`
2. **Карточка «когда писать»** — 4 типа сцен, одним сообщением
3. **Развилки** — сколько угодно раз за 2 недели, когда пишет про сцену
4. **Опционально после 2+ раз** — предложение среза 590 ₽

Нет приложения. Нет ежедневных пушей. Нет сторис-генератора.

---

## Как идти к людям (один абзац)

> Делаю сервис самопознания — не гороскоп. 15 минут вопросов, пришлю разбор, как ты устроен. Потом 2 недели тест: когда в жизни что-то конкретное — показ, тяжёлый разговор, решение, своё дело без дедлайна — пишешь мне, я присылаю короткую развилку под тебя. Нужно 5 человек и честная обратная связь. Бесплатно.

Полные скрипты: `examples/pilot-go-to-market.md`  
Банк развилок: `content/pilot-scene-fork-bank.md`

---

## Как работает операционно (ты / ассистент)

```
Форма → скоринг → разбор (LLM) → Telegram: разбор + карточка сцен
     ↓
Человек пишет: «завтра показ» / «сегодня разговор с…» / «решить уходить»
     ↓
Ты определяешь scene (SHOW / TALK / DECIDE / OWN) + его dominant_node
     ↓
Копируешь развилку из банка → отправляешь → просишь одну строку «что было»
     ↓
День 14: 5 вопросов обратной связи (шаблон в go-to-market)
```

2–3 минуты на одну развилку. Lookup, не придумывать с нуля.

## Метрики пилота (5 человек, 2 недели)

| Метрика | Хорошо | Плохо — меняем гипотезу |
|---------|--------|-------------------------|
| Разбор: «это про меня» | ≥ 3 из 5 | < 2 |
| Хотя бы 1 раз написали про сцену сами | ≥ 3 из 5 | ≤ 1 |
| Развилка: «помогло» / «узнал себя» | ≥ 2 из 5 | 0 |
| «Написал бы снова, когда будет X» | ≥ 3 из 5 | ≤ 1 |
| Готовность 590 ₽ (да / может быть) | ≥ 1 | 0 при сильном «про меня» |

Фиксировать **дословные цитаты**. Не «понравилось».

## Если пилот зелёный

MVP = форма + страница разбора + 4 кнопки сцен + lookup развилок + одна дверь.  
Не daily feed.

## Если пилот красный

Следующая одна гипотеза: **второй человек** (4 вопроса → карта трения). Не смешивать с этой.
