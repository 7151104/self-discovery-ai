# Проверка «зачем возвращаться» — без продукта

> **Статус: заморожено.** Активный пилот — только **[Развилка перед сценой](pilot-go-to-market.md)** ([`docs/15-pilot-scene-fork.md`](../docs/15-pilot-scene-fork.md)). Три гипотезы ниже — архив, не запускать параллельно.

Продукта нет. Пользователей нет. Это нормально.

**Конкретика, с которой работали (архив):**

1. Форма с лестницей (`content/questions-ladder.md`)
2. Разбор вручную: скоринг + LLM по промптам (`docs/09-validation.md`)
3. PDF или длинное сообщение в Telegram — **как будто это и есть продукт**
4. После этого — **не приложение**, а 7–10 дней ручных касаний в Telegram. Три разные гипотезы. Смотрим, за что люди цепляются.

Три вопроса «когда ты открыл бы снова» задаём **не основателю**. Их задаём **пятерым людям после того, как они получили разбор**. До этого — только протокол и демо на вымышленном Алексее.

---

## Шаг 0. Кого зовём

5–10 человек. Не друзья «скажи что круто». Знакомые 25–45, кому правда интересно «как я устроен».

Им: «15 минут вопросов → пришлю разбор. Потом неделю коротких сообщений, скажешь честно — полезно или мусор. Бесплатно.»

---

## Шаг 1. Один раз — разбор (это уже описано в `docs/09-validation.md`)

На выходе у человека:

- текст «как ты устроен»
- один узел
- одна дверь: «Почему ты останавливаешься у финиша» (или другая по селектору)

Записать **дословно** первую реакцию.

---

## Шаг 2. Три гипотезы — три разным людям (или одному по очереди, но тогда смешиваются)

| Гипотеза | Суть | Когда слать |
|----------|------|-------------|
| **A. Перед сценой** | Не «страница дня». Кнопка/сообщение только когда у него что-то назревает | Когда сам пишет «завтра показ» / ты спрашиваешь раз в 2 дня «было что-то из списка?» |
| **B. Второй человек** | Не про него одного. «Добавь одного человека — 4 вопроса — одна карта трения» | День 2 после разбора |
| **C. Зеркало** | Не наш текст. Его отметки → сводка в воскресенье | Каждый вечер 3 кнопки, день 7 — сводка |

**Не смешивать A+B+C одному человеку на первом круге.** Иначе не поймёшь, что сработало.

Рекомендация на первый круг: **2 человека — A, 2 человека — B, 1 человек — C.**

---

## Демо: Алексей, 31, менеджер проектов

Профиль: `examples/demo-person-answers.md`  
Узел: ломается на **показе**, не на работе. Свой проект не показал. Думает об уходе с работы.

Ниже — **готовые сообщения**, как если бы мы уже отправили ему разбор. Это образец для копирования/правки под живого человека с тем же узлом.

---

### Гипотеза A — перед сценой (Алексей)

**День 0.** Разбор получен. Узел: финиш = показ.

**День 3.** Алексей пишет: «Завтра показываю начальнику презентацию.»

**Мы отвечаем (не эссе, 4 строки):**

```
Перед показом.

У тебя обычно ломается не на слайдах. Ломается в момент, когда файл уже можно отправить, а ты ещё «допиливаешь» — потому что пока не показано, оценки нет.

Один вопрос на завтра: что ты боишься услышать первым — «сыро» или «не нужно»?

После — напиши одним словом: отправил как есть / допиливал / не отправил.
```

**Что фиксируем:** ответил ли. Помогло ли (его слова). Открыл бы такое снова перед следующей сценой — да/нет.

**Платная дверь (только если A сработала 2+ раза):**

```
Ты два раза перед показом поймал одно и то же. Откуда это — не из бесплатных ответов. 8 вопросов про остановки у финиша — 590 ₽.
```

---

### Гипотеза B — второй человек (другой пользователь, не обязательно Алексей)

**День 1 после разбора:**

```
В разборе — ты. Часто возвращаются не за «ещё про себя», а за «почему мы с [имя] так».

Напиши имя одного человека (муж, начальник, мама — кого угодно). 4 коротких вопроса про него — пришлю одну карту: где вы обычно трётесь и что тебе не говорить в разговоре.
```

4 вопроса — черновик, не финальный банк:

1. Он/она когда злится — молчит, давит или уходит?
2. Тебя в этом раздражает больше — или задевает?
3. Последний раз вы не сошлись — из‑за чего одной фразой?
4. Ты в том разговоре — давил, закрылся или уступил?

**Выход:** 5–7 предложений «где трётесь» + «не говори X, лучше Y» — из **его** профиля + ответов про другого. Без «вы не подходите».

**Что фиксируем:** дал ли имя. Переслал ли карту тому человеку. Попросил ли разбор для второго.

---

### Гипотеза C — зеркало (Алексей)

**Каждый вечер 4 дня (не 7 на первом круге — хватит):**

```
Сегодня из твоего узла — что было?

1 — почти отправил/показал, но допиливал
2 — было давление/критика, ушло внутрь
3 — своё дело стояло, чужое делал
0 — ничего из этого

Цифра одна.
```

**День 5 — сводка:**

```
За 4 дня: [N] раз допиливал вместо показа, [N] раз своё стояло.

Это не настроение. Это один и тот же узел из разбора.

Хочешь разобрать, откуда — 8 вопросов, 590 ₽. Не хочешь — ок, просто зеркало.
```

**Что фиксируем:** отвечал ли цифрой. Совпала ли сводка с ощущением «это правда».

---

## Что считаем успехом (не «понравилось»)

| Сигнал | Значит |
|--------|--------|
| Сам написал «завтра показ / разговор / решение» | A живёт |
| Спросил «а можно ещё раз перед…» | A — кандидат в продукт |
| Дал имя второго человека | B живёт |
| «Сделай моей жене» / переслал | B + виральность |
| 3+ вечера жмёт цифру без напоминания | C живёт |
| После сводки спросил про 590 ₽ или «откуда это» | воронка работает |
| «Это опять то же самое / как гороскоп / вода» | гипотеза мёртва, не polish |

**Порог «идём в продукт»:** хотя бы у **2 из 5** людей один сигнал сильный + они сами формулируют, **зачем** вернулись бы (дословно).

---

## Что НЕ делаем на этом этапе

- Не пишем код ежедневной страницы
- Не генерим красивые карточки для сторис
- Не выбираем «колода vs глава»
- Не просим основателя «представь, что ты пользователь»

**Делаем:** 5 людей → разбор → одна гипотеза → их слова → одно решение.

---

## Следующий артефакт после прогона

Один документ на 1 страницу:

- какая гипотеза выиграла
- 3 дословные цитаты пользователей
- один экран MVP (что буквально на нём: кнопки, не абзацы)
- одна дверь и когда её показывать

Только после этого — снова обсуждать ежедневный слой в продукте.
