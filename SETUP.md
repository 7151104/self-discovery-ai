# Быстрый старт

## Для нового агента Cursor

```
Прочитай AGENT-BOOTSTRAP.md и продолжай проект. Архитектуру не менять.
Где мы и что дальше: docs/14-state.md → docs/13-roadmap.md → docs/12-target-state.md.
Задачу бери по идентификатору из маршрута. Живых людей пока не запускаем.
```

## Запуск

```
npm install
npm test        # тесты движка, целостности контента и сервера
npm run serve   # кликабельный прототип на http://localhost:5173
```

После правки любого файла в `content/` пересборка не нужна вручную: `npm test` и
`npm run serve` сами пересобирают данные из markdown.

## Сервер и база

Внешних сервисов и демонов не нужно: база — файл, он создаётся при первом старте,
непринятые миграции применяются сами.

```
npm run dev:server   # http://127.0.0.1:8787
curl http://127.0.0.1:8787/api/health
```

Миграции отдельной командой:

```
npm run migrate -- status      # что применено, что нет
npm run migrate -- up          # чистая база с нуля
npm run migrate -- down        # откат последней миграции
npm run migrate -- reset       # откатить всё и накатить заново
```

Настройки — только через переменные окружения. Состав описан в `.env.example`;
значений там нет, скопировать в `.env` и заполнить. Для разработки хватает
значений по умолчанию: обязательные переменные проверяются при `SDAI_ENV=production`,
и без любой из них сервер не стартует, а пишет её имя.

Что где лежит и какие есть эндпоинты — `server/README.md`.

## Структура

- `AGENT-BOOTSTRAP.md` — вход для AI-агента
- `docs/` — концепция, архитектура, UI-сценарий, цель (`12`), маршрут (`13`), состояние работы (`14`)
- `content/` — вопросы, скоринг, тексты ступеней, доборы платных срезов
- `prompts/` — промпты для LLM
- `examples/` — демо для калибровки
- `engine/` — Rule Engine: читает контент, считает координаты, выбирает узел и предложение
- `server/` — транспорт и хранение: контракт API, база, постоянная ссылка на страницу
- `prototype/` — личная страница на движке
