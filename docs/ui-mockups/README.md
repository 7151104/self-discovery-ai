Концепт-арт интерфейса, сгенерированный как визуальный якорь перед прототипом.  
Рабочее имя бренда в макетах — **координаты**. Это не утверждённое имя продукта.

## Система

- Фон: тёплый почти-чёрный, зерно
- Текст: кремовый
- Акцент: медь / терракота
- Крупные хуки — антиква; UI — гротеск
- Наружу не выходят MBTI, знаки зодиака, проценты, витрина продуктов

## Что брать в прототип

1. Хук крупнее имени — страница должна читаться со скриншота.
2. Карта — полосы пигмента, не радар и не проценты.
3. После бесплатного — **одна** дверь, остальные видны как маршрут.
4. Дата рождения даёт визуал карточки, не характер.

## Три альтернативных набора

Один каркас продукта (вход → порция вопросов → страница → карта → одно предложение), три характера. В каждом наборе 6 экранов: лендинг, карточка периода, вопросы, личная страница, карта, paywall.

| Набор | Папка | Характер | Когда брать |
|-------|-------|----------|-------------|
| A · досье | `alt-a-dossier/` | Светлая бумага, чернила, сургуч, клиника-архив | Если продукт должен казаться кабинетом, не приложением |
| B · прибор | `alt-b-instrument/` | Холодная сетка, тил, каналы сигнала | Если дифференциатор — «система», не журнал |
| C · утро | `alt-c-morning/` | Дневной свет, глина, лён, editorial | Если страница должна жить в сторис и на кухне |

Первый набор в корне папки — тёмный editorial с медью. Четыре направления вместе — развилка визуала, не четыре продукта.

В прототипе у B не тащить ползунки и «железо» буквально: каналы без цифр. У A — без почтовых штемпелей как бренда. У C — без lifestyle-фото вместо интерфейса.
