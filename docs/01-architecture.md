# 01. Архитектура системы

## Четыре слоя

```
┌─────────────────────────────────────────────────────────┐
│  СЛОЙ 4: ВЫХОД                                         │
│  Отчёты, блоки страницы, визуал, платные срезы         │
├─────────────────────────────────────────────────────────┤
│  СЛОЙ 3: СОГЛАСОВАНИЕ                                  │
│  Лестница источников, расхождения, регистры речи       │
├─────────────────────────────────────────────────────────┤
│  СЛОЙ 2: ЯДРО — 16 КООРДИНАТ                           │
│  value + confidence + source + flags                   │
├─────────────────────────────────────────────────────────┤
│  СЛОЙ 1: СБОР                                          │
│  Вопросы порциями, дата рождения, открытые ответы      │
└─────────────────────────────────────────────────────────┘
         ▲                    ▲                    ▲
         │                    │                    │
    Эшелон 1            Эшелон 2            Эшелон 3
   (измеряемое)    (интерпретация)      (символика)
```

## Поток данных

```
Имя + дата → карточка входа (без выводов о личности)
     ↓
Порция вопросов → Rule Engine → обновление Profile
     ↓
Ступень 1-3: lookup готовых текстов по ответам
Ступень 4+: LLM(prompt + Profile + открытый текст)
     ↓
Блоки на личной странице (накапливаются)
     ↓
Selector следующего шага → одно платное предложение
```

## Два режима генерации

| Режим | Когда | Почему |
|-------|-------|--------|
| **Lookup (готовые тексты)** | Ступени 1–3, первые 11 вопросов | Мало данных; LLM будет лить воду; нужна скорость и предсказуемость |
| **LLM-синтез** | Ступень 4, полные и платные отчёты | Достаточно координат; нужен синтез и персонализация |

## Личная страница

Не PDF. Живая страница на домене:
- Визуальная карта (6–8 полос) — виральный объект
- Заполненные блоки по ступеням
- Закрытые двери с подписями под профиль человека
- Часть дверей открывается ответами, часть — деньгами
- Карта всего маршрута видна сразу (не paywall-сюрпризы)

## Rule Engine (для кода)

Вход: `{ question_id: answer }`  
Выход: `Profile` — JSON с 16 координатами:

```json
{
  "coord_11": {
    "value": "рвётся на 80%",
    "band": "high",
    "confidence": "high",
    "sources": ["Q24:C", "Q25:5"],
    "flags": ["self_report_mismatch: Q23=4 vs Q24=C"]
  }
}
```

Правила: `content/scoring-rules.md`

## Что заменяемо без переписывания продукта

- Любая модель эшелона 2–3 → меняется mapping в координаты
- LLM-провайдер
- UI-фреймворк
- Платёжка

## Что НЕ заменяемо

- 16 координат как внутренний язык
- Правила согласования
- Лестница входа (ценность до шага)
- Закон новых данных для платных срезов
