# Кликабельный прототип воронки

Мобильный проход: подарок → вопросы порциями → страница → узел → 590 ₽ → разбор → шаринг.

Тексты ступеней 1–3 — lookup из `content/`, не LLM. Сюжет ступени 4 — шаблон.

## Как открыть

```bash
cd prototype
python3 -m http.server 4173
```

Открой http://127.0.0.1:4173/ с телефона или узким окном.

Кнопка **«Пройти путь Ани»** сразу ставит ответы демо-профиля и открывает первый удар.

## Что проверить пальцем

1. Имя + дата → карточка периода
2. Три вопроса → сторис-хук → страница
3. Вкладки: Я / Дальше / Карта / Ещё
4. До узла и открытого вопроса
5. 590 ₽ → 8 вопросов среза → «что с этим делать»
6. Поделиться страницей, не тестом
