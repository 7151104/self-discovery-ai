# 00. Видение продукта

## Проблема

Человек хочет понять себя — сильные стороны, слабости, мотивы, выборы. Сейчас он идёт в **одну** систему (MBTI, астрология, психолог, Human Design) и получает **одну оптику**. Системы спорят между собой, если смешивать их в одном тексте.

## Решение

Сервис, который:
1. Собирает данные о человеке через вопросы (порциями, без тяжёлого входа)
2. Прогоняет через множество моделей **внутри**, переводя всё в 16 координат
3. Согласовывает противоречия по правилам
4. Выдаёт **один связный разбор** на человеческом языке (без названий методик)
5. Ведёт по **маршруту срезов** — как платная клиника: сначала общее, потом то, что нужно именно тебе

## Для кого

- Старт: русскоязычная аудитория 25–45, интерес к самопознанию
- Потом: международный рынок
- Параллельно: B2B для психологов/коучей (инструмент под их брендом)

## Чем НЕ является

- Не терапия, не диагностика, не гороскоп
- Не «один тест — один PDF навсегда»
- Не лицо-инфобизнес (основатель не светится)

## Три дифференциатора

1. **Согласование** — модели усиливают друг друга через координаты, не создают хаос
2. **Маршрут** — не один отчёт, а путь из срезов под запрос
3. **Личная страница** — накапливается, виральна (скриншот + ссылка), удерживает

Как страница становится настольной книгой (ежедневный Сигнал + артефакт в соцсети, не гороскоп): `docs/11-daily-ritual-and-social.md`.

## Уникальность на старте

На русском рынке нет сильного продукта, который делает именно **согласованный мульти-модельный** разбор с **маршрутом покупок**. Есть отдельные тесты, есть эзотерика, есть коучи — нет «системы координат + путь».

## Риски (принятые)

| Риск | Митигация |
|------|-----------|
| Второй отчёт = пересказ первого | Закон 2: новые данные для каждого среза. Ежедневный слой не пишет новую личность — крутит рабочую поверхность + наблюдение |
| Ежедневность скатится в гороскоп | Сигнал проверяем, lookup-банк, дата не питает линзу |
| Тяжёлый вход | Лестница порциями, ценность после каждой |
| Платный трафик не окупается | Виральность страницы + партнёры |
| LLM льёт воду | Промпты, анти-Barnum, готовые тексты на входе |
| Эзотерика портит репутацию | Эшелон 3: нулевое право утверждать |
| Основатель не лицо | Продукт = артефакт; B2B для практиков |
