# Лестница входа — 11 закрытых + 1 открытый

Бесплатный продукт. Порядок важен: каждая порция оплачена наблюдением перед следующей
(Закон 1). Это же — источник текста для формы ручного прогона и для кликабельного прототипа.

Шкальные вопросы: **1 — совсем не про меня … 5 — точно про меня**.

---

## Формат записи (не менять — по нему читает движок)

```
### {id} · {тип} · {источник в full bank} · координаты {список}

**{текст вопроса, который видит человек}**

- **A** — {вариант}          ← только для типа «выбор»
Шкала: 1 — {левый полюс} · 5 — {правый полюс}   ← только для типа «шкала»
```

Тип: `выбор` · `шкала` · `открытый`. Парсер: `engine/scripts/build-content.mjs`.

---

## Ступень 0 — вход

Поля формы, не вопросы координат:

- **Имя** — обязательно, 1–40 символов
- **Дата рождения** — можно пропустить. Пропуск: «без даты — без карточки периода»

Выход: `content/step0-welcome.md`. Выводов о личности из даты — ноль.
