# Быстрый старт

## Для нового агента Cursor

```
Прочитай AGENT-BOOTSTRAP.md и продолжай проект. Архитектуру не менять.
```

## Запуск

```
npm install
npm test        # 30 тестов движка и целостности контента
npm run serve   # кликабельный прототип на http://localhost:5173
```

После правки любого файла в `content/` пересборка не нужна вручную: `npm test` и
`npm run serve` сами пересобирают данные из markdown.

## Структура

- `AGENT-BOOTSTRAP.md` — вход для AI-агента
- `docs/` — концепция, архитектура, UI-сценарий
- `content/` — вопросы, скоринг, тексты ступеней, доборы платных срезов
- `prompts/` — промпты для LLM
- `examples/` — демо для калибровки
- `engine/` — Rule Engine: читает контент, считает координаты, выбирает узел и предложение
- `prototype/` — личная страница на движке
