# Как перенести проект на другой аккаунт Cursor

## Что нельзя перенести

- **Сам Cloud Agent** — привязан к аккаунту-владельцу
- **Историю чата** автоматически — только вручную
- Ссылка https://cursor.com/agents/bc-01a07185-8d85-7333-85d2-133106afe504 работает только со старого аккаунта

## Что переносится (всё ценное)

**Весь этот репозиторий.** Он содержит:
- Архитектуру и 16 координат
- Правила согласования
- Полный банк вопросов + лестницу входа
- Готовые тексты ступеней 1–3
- Движок противоречий
- Промпты LLM
- Маршрут монетизации
- Бизнес-контекст и решения основателя
- Демо для калибровки

## Пошаговая инструкция

### Шаг 1. Забрать файлы со старого агента

**Вариант A — Git (рекомендуется):**
```bash
# На старом агенте (если есть git):
git init
git add .
git commit -m "Full project handoff package"
git remote add origin https://github.com/YOUR_USER/self-discovery-ai.git
git push -u origin main
```

**Вариант B — Скачать папку:**
- В UI Cloud Agent скачай `/agent` целиком
- Или скопируй все файлы вручную

**Вариант C — Архив:**
```bash
cd /agent && zip -r handoff.zip .
```

### Шаг 2. Новый аккаунт Cursor

1. Создай репозиторий на GitHub с содержимым пакета
2. **New Cloud Agent** → выбери репозиторий
3. Или **Cursor Desktop** → Open Folder

### Шаг 3. Первое сообщение новому агенту

```
Подхватываем проект AI-самопознания. Репозиторий — полный handoff.

НАЧНИ С: AGENT-BOOTSTRAP.md (прочитай полностью)
ПОТОМ: docs/01 → 02 → 04 → 05 → content/scoring-rules → step1-branches → step3-contradictions
ЭТАЛОН КАЧЕСТВА: examples/demo-report-output.md

Статус: активная разработка. Архитектуру не пересматривать.
Код не начат. Контент и логика — готовы.

Текущая задача: [УКАЖИ]
```

### Шаг 4. Проверка, что агент подхватил

Попроси нового агента:
1. Перечислить 16 координат
2. Объяснить, почему ступени 1–3 без LLM
3. Назвать dominant_node для demo-person-answers.md
4. Сформулировать первое платное предложение для NODE_FINISH_FEAR

Если ответы верные — handoff успешен.

## Опционально: сохранить историю старого чата

1. Открой старый агент в браузере (старый аккаунт)
2. Скопируй ключевые сообщения или экспортируй transcript
3. Положи в `archive/original-chat-notes.md` — не обязательно, всё важное уже в репо
