## Команды проверки

Полный прогон локально и в CI (`.github/workflows/ci.yml`):

```bash
npm install
npm test                  # движок, сервер, LLM, web, снимки, a11y, e2e, load
npm run lint:content      # запрещённые формулировки, Barnum, объёмы
npm run lint:styles       # токены, без литеральных цветов и отступов
npm run lint:budget       # вес скриптов/стилей, число модулей, без веб-шрифта
npm run snapshots         # визуальные регрессии s0–paid_done
npm run test:a11y         # доступность, цели 44 px, клавиатура
npm run test:e2e          # бесплатный, платный, кризисный и возвратный пути
npm run test:load         # очередь генерации на всплеске
npm run migrate:check     # совместимость миграций
npm run test:coverage:engine  # покрытие engine/dist, без generated; отказ ниже 90% строк
npm run verify            # test + lint:content + lint:styles + lint:budget + migrate:check + покрытие engine
```

Дополнительно (не в каждом прогоне): `npm run funnel`, `npm run check:health`,
`npm run pay` (тестовая оплата).
