## Живой демо-сервер (не постоянный)

Туннели **Serveo / Cloudflare trycloudflare** живут часы, не дни. После сброса чатов
**старые ссылки не работают**. Поднять заново:

```bash
npm run build
export SDAI_HOST=0.0.0.0 SDAI_PORT=8788 SDAI_DB_PATH=/tmp/sdai-live/app.db \
  SDAI_BACKUP_DIR=/tmp/sdai-live/backups SDAI_DB_AUTO_MIGRATE=1 \
  SDAI_PAYMENT_PROVIDER=fake SDAI_LLM_PROVIDER=stub SDAI_TRUST_PROXY=1
# SDAI_ENCRYPTION_KEY — npm run keygen, в .env, не в git
node --disable-warning=ExperimentalWarning server/dist/main.js
# + ssh -R 80:127.0.0.1:8788 serveo.net  или  cloudflared tunnel --url http://127.0.0.1:8788
```

Без `SDAI_LLM_API_KEY` ступень 4 и платные срезы — **заглушка**, не литература.

ещё draft, E12-02 не начат, `main` отстаёт на ~254 коммита — слияние лучше одним
шагом позже, когда основатель скажет «в прод».

**Рабочая ветка:** `cursor/mobile-textarea-focus-64b0` (PR #9, кончик цепочки).

**Когда слить в `main`:** после подписи визуала или по явной команде основателя —
тогда снизу вверх PR #1 → #2 → #4 → #5 → #6 → #8 → #9.
