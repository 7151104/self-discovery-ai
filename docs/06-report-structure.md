# 06. Структура отчёта

Каркас из семи частей общий для **полного бесплатного разбора**, платных срезов и полной
карты. Тематические срезы отличаются **набором подсвеченных координат** и глубиной.

**Финал лестницы на этом каркасе не строится** — у него свой сюжет из трёх абзацев.
Различие двух бесплатных отчётов — в разделе ниже.

---

## Два бесплатных отчёта

| | Финал лестницы | Полный бесплатный разбор |
|---|---|---|
| Машинный тип | `финал_лестницы` | `бесплатный_полный` |
| Место в маршруте | блок ступени 4 внутри лестницы 11+1 | **входа в продукте нет** — формат ручного прогона по полному банку 35+3 |
| Каркас | 3 абзаца: сюжет — механизм круга — обрыв | семь частей, п.5 «Что с этим делать» пропущен |
| Объём | 250–350 слов | 900–1200 слов |
| Источник | `content/step4-open-synthesis.md` | `prompts/full-report-assembler.md` |

Это разные отчёты: по объёму, по каркасу и по входу. Валидатор объёма различает их по
машинному типу.

**Полный бесплатный разбор в первом релизе пользователю не выдаётся.** Отдельного
бесплатного входа на 38 вопросов нет: форма такого размера до первой ценности нарушает
Закон 1, а бесплатно закрытые 16 координат обнуляют маршрут (`docs/14-state.md`, блок
решений «Продукт и маршрут»). Формат остаётся как инструмент ручного прогона по банку:
на нём собран `examples/demo-report-output.md` и калибруются формулировки банка (E5-11).
Пользователю те же 16 координат приходят платно — срезом `slice_full_map`.

---

## Семь частей

### 1. Портрет
5–7 утверждений только с **high confidence**.  
Задача: «да, это про меня» за 30 секунд.  
Первое предложение — самое точное во всём тексте.

### 2. Ядро напряжения
2–3 внутренних противоречия из flags и расхождений.  
Самая сильная часть. Пишется сильнее остальных.

### 3. Механика в жизни
3 конкретные сцены: работа, решения, давление.  
Сцена = узнаваемая ситуация с деталью.  
**Не повторять** раздел 2 другими словами.

### 4. Цена сильных сторон
2 пары: сила + обратная сторона из **той же** координаты.

### 5. Что с этим делать
3–5 действий, привязанных к координатам этого человека.  
Невозможны для другого профиля.  
Никаких универсальных советов.

### 6. Опора
1 линия мыслителей (см. `docs/03-models-and-tiers.md`).  
1 приём + 1 вопрос + 1 книга.

### 7. Чего я о тебе пока не знаю
3 пункта. Честное ограничение + воронка.  
В полном бесплатном разборе (`бесплатный_полный`) — **без решения** в п.5 (решение за
платной дверью).

## Объём

| Отчёт | Машинный тип | Слов |
|-------|--------------|------|
| Блок ступени 1–3 (lookup) | — | 80–150 на блок |
| Финал лестницы (LLM) | `финал_лестницы` | 250–350 |
| Полный бесплатный разбор (LLM, ручной прогон) | `бесплатный_полный` | 900–1200 |
| Платный срез | `срез_узел`, `срез_работа`, `срез_отношения`, `разбор_решения` | 800–1200 |
| Полная карта | `полная_карта` | 1500–2500 |

---

## Оформление (шаблон страницы)

1. **Страница 1:** имя, дата, фраза-крючок (крупно) — для скриншота
2. **Страница 2:** визуальная карта (7 полос, без цифр и %)
3. **Далее:** разделы с воздухом, один раздел = одна «экранная» порция
4. **Последняя:** «чего не знаю» + одна строка приглашения

## Тематические срезы — какие координаты подсвечивать

| Срез | Координаты | Добор вопросов |
|------|------------|----------------|
| Узел (финиш/оценка) | 8, 9, 11, 15 | 8–10 про историю остановок |
| Работа / реализация | 3, 4, 6, 11, 13, 14 | 15–20 про опыт работы |
| Отношения | 8, 9, 12, 15 | 15–20 про историю связей |
| Решение (развилка) | 4, 5, 10, 14, 16 | описание ситуации + 5–8 |
| Совместимость | сравнение двух профилей | второй профиль целиком |
| Полная карта | все 16 | остаток полного банка (24 закрытых) + `О2`, `О3`, тремя порциями |

Добор полной карты — это вопросы `content/questions-full-bank.md`, на которые человек ещё
не отвечал: лестница закрывает 11 закрытых вопросов банка и `О1`, доборы других срезов
вопросов банка не содержат. Порядок выдачи и порог — `prompts/paid-slice-templates.md`,
раздел `slice_full_map`.
