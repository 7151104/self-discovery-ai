# 10 мобильных систем

Не сжатый десктоп: у каждого варианта своя навигация, своё меню и свой способ пройти лестницу.

**Смотреть этот файл на GitHub** — картинки откроются в браузере:  
https://github.com/7151104/self-discovery-ai/blob/cursor/ui-mockups-ten-interfaces-e6f8/docs/ui-mockups/mobile-10/GALLERY.md

По три экрана на систему: дом / действие / меню или маршрут.

| # | Система | Где меню | Как идут вопросы |
|---|---------|----------|------------------|
| 01 | Страница-артефакт | На самой странице, без бургера | Порция, кнопка «ещё N» |
| 02 | Истории | Финальная сторис-карточка | Тап вправо, прогресс сверху |
| 03 | Нижние вкладки | Вкладка «Маршрут» | Вкладка «Вопросы» |
| 04 | Чат | Лист по кнопке (i) | Сообщение + чипы ответа |
| 05 | Свайп-колода | Экран «колода» | Карточка ответа влево/вправо |
| 06 | Постер + бургер | Полноэкранный индекс ≡ | Из пункта «Вопросы» |
| 07 | Мастер ступеней | Список в конце мастера | Один экран = один шаг |
| 08 | Лента вверх | Последний рил / «ещё» | Свайп вверх по блокам |
| 09 | Карта + шиты | Шиты под картой | Вопрос в нижнем шите |
| 10 | Нативный iOS | Вкладка «Ещё» | Push-экран ступени |

## 01. Страница-артефакт

Продукт = одна живая страница. Меню нет: функции лежат внизу скролла. Лучше всего скриншотится.

**Функции на странице:** поделиться, ссылка, закрытые двери, одно предложение 590 ₽, «ещё N вопросов».

**Меню** = последняя сторис «что дальше»: страница, шаринг, узел, карта.

## Что брать в прототип

На телефоне почти наверняка побеждает **гибрид 01 + 03 + 10**:

1. Дом — страница-артефакт (скриншот, хук, карта, двери).
2. Низ — две-четыре вкладки, не десять пунктов в бургере.
3. Вопросы — отдельный поток на большой палец, порциями.
4. «Ещё» — совместимость, тема, выход. Платные двери живут на странице и во вкладке «Маршрут», не в настройках.

Не тащить в MVP чат, рилсы и свайп как основу: они хороши как эксперимент входа, но ломают закон «живая страница на домене».

Это концепт-арт. Кириллица и лишние вкладки в генерации могут плыть. Канон — `docs/05-user-journey.md`.
