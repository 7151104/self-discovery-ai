# Ступень 4 — LLM-синтез (открытый вопрос)

**Только LLM.** Вход: profile + dominant_node + открытый ответ L12 (О1).

---

## Промпт

```text
На входе:
1) Профиль координат (JSON или таблица)
2) ID и текст показанного узла (ступень 3)
3) Тексты блоков ступеней 1–2 (уже показанные пользователю)
4) Открытый ответ на вопрос: «Что в твоей жизни повторяется из раза в раз, хотя тебе это не нравится?»

Напиши финальный блок бесплатного разбора.

ОБЪЁМ: 250–350 слов, 3 абзаца, обращение на «ты».

АБЗАЦ 1 — Сюжет
Назови повторяющийся сюжет его собственными словами. Минимум одна фраза из ответа — дословно.

АБЗАЦ 2 — Механизм круга
Соедини сюжет с механизмом из ступеней 1–3 и узлом. Покажи: с чего начинается → где ломается → почему возвращается. Это объяснение, которого не было раньше.

АБЗАЦ 3 — Обрыв
Назови 2–3 вещи, которые остались неизвестны. Без советов. Без утешения. Последняя фраза — точная и без выхода.

ЗАПРЕЩЕНО:
- диагнозы, медицина, предсказания
- предназначение, энергия, миссия, вибрации
- названия методик и типологий
- Barnum, лесть
- советы и «что делать»

РЕГИСТРЫ: только по confidence координат.

КРИЗИС в открытом ответе → не писать блок, выдать кризисный текст (см. prompts/full-report-assembler.md).

Выведи только текст блока. Заголовок: «Твой повторяющийся сюжет»
```
