# Пилот «Развилка перед сценой» — go to market

**Один продукт на 2 недели.** Не три гипотезы. Не ежедневный текст. Не приложение.

Спека: [`docs/15-pilot-scene-fork.md`](../docs/15-pilot-scene-fork.md)  
Банк развилок: [`content/pilot-scene-fork-bank.md`](../content/pilot-scene-fork-bank.md)

---

## Чеклист перед первым сообщением

- [ ] Google Form с L1–L11 + L12 (см. раздел «Форма»)
- [ ] Telegram для ответов (личный или отдельный аккаунт — не важно)
- [ ] Таблица: имя | dominant_node | scene_1 | fork_1 | quote | …
- [ ] 5 человек в списке (не «скажи что круто»)

---

## 1. Текст приглашения (copy-paste)

Отправляешь **5 знакомым** 25–45, кому правда интересно «как я устроен». Не друзьям «поддержи стартап».

```
Привет. Тестирую одну штуку — не гороскоп и не тест из журнала.

15 минут вопросов → пришлю разбор, как ты устроен (текстом в Telegram).

Потом 2 недели: когда в жизни что-то конкретное —
• показ / отправить / сдать
• тяжёлый разговор
• решение (уйти, выбрать, зафиксировать)
• своё дело без дедлайна

— пишешь мне одной фразой, я отвечаю короткой развилкой под тебя (30 секунд чтения). Не каждый день. Только когда случится.

Нужно 5 человек и честная обратная связь в конце. Бесплатно. Займёт?

[ссылка на форму]
```

Если спрашивают «это психолог?»:

```
Нет. Это разбор паттернов по ответам — как ты обычно ломаешься в конкретных ситуациях. Не диагноз, не терапия. Если тебе нужна помощь специалиста — это не замена.
```

---

## 2. Форма (Google Form)

**Название:** Разбор + тест «перед сценой» (2 недели)

**Описание в форме:**

```
15 минут. После — разбор в Telegram в течение 1–2 дней.
2 недели: когда случится одна из «сцен» — напишите мне в Telegram, пришлю короткую развилку.
В конце — 5 вопросов (5 минут). Спасибо за честность.
```

**Поля:**

| Поле | Тип |
|------|-----|
| Имя (как обращаться) | короткий текст |
| Telegram (@ или номер) | короткий текст |
| L1–L11 | как в `content/questions-ladder.md` — варианты A/B/C… |
| L12 (открытый) | абзац: «Что у тебя повторяется снова и снова, хотя каждый раз обещаешь себе по-другому?» |

Полный банк вопросов: `content/questions-full-bank.md` (для подписей к L1–L11).

## 3. День 0 — разбор + карточка «когда писать»

### Операционка

1. Ответы из формы → скоринг по `content/scoring-rules.md`
2. Ступени 1–3: lookup из `content/step1-branches.md`, `step2-branches.md`, `step3-contradictions.md`
3. Ступень 4 + сборка: LLM по `prompts/full-report-assembler.md`, чеклист `docs/09-validation.md`
4. Записать **dominant_node** (например `NODE_FINISH_FEAR`)
5. Отправить в Telegram **два сообщения подряд**

### Сообщение A — разбор

Структура как в `docs/06-report-structure.md`. Коротко для пилота достаточно:

- «Как ты устроен» (3–5 абзацев)
- «Внутреннее напряжение» (1 абзац — самый сильный)
- «Твой узел» — одно предложение человеческим языком (не NODE_* наружу)

**Не включать** платный срез целиком. Одна строка в конце:

```
Если захочешь разобрать, откуда этот узел — напишу отдельно (это уже платная часть, в тесте бесплатно не даём).
```

### Сообщение B — карточка сцен (copy-paste)

```
Когда писать мне следующие 2 недели
(не каждый день — только когда случится)

🟦 ПОКАЗ — отправить, сдать, выложить, презентация, «надо показать людям»
🟨 РАЗГОВОР — созвон, конфликт, критика, «нас обсудят», тяжёлый разговор
🟥 РЕШЕНИЕ — уйти/остаться, выбрать одно, зафиксировать, не откладывать
🟩 СВОЁ — side project, своё дело, «надо бы начать», без внешнего дедлайна

Как писать: одной фразой + что за сцена.
Пример: «завтра показ начальнику, ПОКАЗ» или «сегодня разговор с женой про деньги, РАЗГОВОР»

Отвечу короткой развилкой + один вопрос. Потом попрошу одну строку — что было на самом деле.
```

## 4. Когда человек пишет про сцену

### Твои шаги (2–3 минуты)

1. Прочитать сообщение
2. Определить **scene**: SHOW / TALK / DECIDE / OWN (таблица в банке)
3. Взять **dominant_node** из разбора
4. Скопировать блок из `content/pilot-scene-fork-bank.md`
5. Отправить **без правок**, если текст ложится. Максимум — подставить «завтра» / имя из их сообщения в первую строку
6. После сцены — попросить одну строку (уже в конце блока)

### Если scene непонятна

```
Уточни одним словом: это больше про показ, разговор, решение или своё дело без срока?
```

### Если node в банке нет

Ближайший по смыслу из 6 узлов. Записать в таблицу «node mismatch» — поправим банк после пилота.

### Пример (Алексей, NODE_FINISH_FEAR, SHOW)

Человек пишет: «завтра показываю мVP инвестору»

→ блок SHOW для NODE_FINISH_FEAR из банка.

## 5. После 2+ развилок (опционально, не навязывать)

Если человек сам вернулся и хотя бы раз написал «помогло» / «узнал себя»:

```
Ты уже два раза поймал свой узел в живых сценах. Есть срез «откуда это и что с этим делать» — обычно 590 ₽, в тесте спрашиваю только: было бы интересно / может быть / нет. Без оплаты сейчас.
```

Записать ответ дословно.

## 6. День 14 — обратная связь (copy-paste)

```
Спасибо, что участвовал. Последнее — 5 коротких вопросов, ответь как есть, не вежливо:

1. Разбор в начале — насколько «это про меня»? (0–10)
2. Писал ли ты мне про сцену сам, без напоминания? (да / нет / один раз после напоминания)
3. Если писал — развилка помогла или нет? Одной фразой.
4. Написал бы снова, когда случится похожая сцена? (да / нет / не знаю)
5. Срез «откуда узел» за ~590 ₽ — (да / может быть / нет)

И если можешь — одна цитата дословно: что запомнилось или что бесило.
```

**Не писать первым** «ну как, понравилось?» — только этот опрос.

## 8. Критерии «идём дальше / меняем гипотезу»

См. [`docs/15-pilot-scene-fork.md`](../docs/15-pilot-scene-fork.md).

**Зелёный:** ≥3 «про меня», ≥3 написали про сцену сами, ≥2 «помогло», ≥3 «написал бы снова».  
**Красный:** люди не пишут про сцены сами → следующая одна гипотеза «второй человек», не смешивать.

---

## 9. Чего не делать в пилоте

- Ежедневные сообщения «на всякий случай»
- Три разные гипотезы одному человеку
- Генерировать развилки LLM с нуля (только банк)
- Просить основателя «ответить как пользователь»
- Сторис, картинки, приложение

---

## 10. Напоминание (только если молчат 7+ дней)

Один раз, не чаще:

```
Привет. Как тест — если за неделю была сцена из карточки (показ / разговор / решение / своё), можешь кинуть одной фразой. Если не было — просто молчи, это тоже ответ.
```

Если после напоминания никто не пишет — это сигнал, не провал участника.
