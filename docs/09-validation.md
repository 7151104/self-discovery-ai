# 09. Валидация и качество

**Когда.** Прогон на живых людях — **последний этап маршрута** (`docs/13-roadmap.md`, E12),
а не первый шаг. Запускается только после того, как закрыт раздел «Условие перехода к живым
людям» в `docs/12-target-state.md`: техническая и визуальная части готовы полностью, путь
от ссылки до платного отчёта проходится без участия агента. Реакция на черновик измеряет
черновик, а переписывать тексты дважды — потерянная работа.

Чеклист качества текста и памятка наблюдений ниже применяются раньше и постоянно: к
синтетическим профилям (E11-08) и к любому новому тексту.

## Прогон на людях (этап E12)

**Инструмент:** сам продукт по постоянной ссылке; ручные шаги со стороны агента запрещены —
иначе измеряется не продукт  
**Объём:** 30 человек минимум, 50 оптимально  
**Стоимость:** 0 ₽ плюс себестоимость генераций

### Процесс

1. Человек проходит лестницу из `content/questions-ladder.md` на своей странице
2. Скоринг — движком по `content/scoring-rules.md`
3. Ступени 1–3: lookup текстов, без LLM
4. Ступень 4 и платные срезы: генерация с валидацией выхода
5. Оформление — страница по `docs/11-ui-page-spec.md` и каркас `docs/06-report-structure.md`
6. Фиксация реакций по памятке ниже и сверка с событиями воронки

---

## Памятка наблюдений (на каждого человека)

| # | Что фиксировать |
|---|-----------------|
| 1 | Первая реакция — **дословно** |
| 2 | Удивление («откуда знаешь») — да/нет |
| 3 | С чем **не согласился** — конкретные пункты |
| 4 | Переслал ли **сам** (без просьбы) |
| 5 | Попросил разбор для другого |
| 6 | Уточняющий вопрос по содержанию |
| 7 | Вернулся через несколько дней |

**Не спрашивать:** «понравилось?» — вежливость = мусор.

---

## Целевые метрики (30 человек)

| Метрика | Порог «идём дальше» | Порог «переделываем ядро» |
|---------|---------------------|---------------------------|
| Удивление | ≥ 10/30 (33%) | < 3/30 |
| Пересыл / «сделай моему» | ≥ 6/30 (20%) | 0 |
| Несогласие | ≤ 2 пункта/разбор в среднем | > 4 пункта |
| Оплата 2-го среза | ≥ 1 из 30 | 0 при сильном удивлении |

---

## Чеклист качества текста

Перед выдачей любого разбора:

- [ ] Первая фраза точная и небанальная?
- [ ] Каждое утверждение проверяемо?
- [ ] Ни одно не подходит половине людей?
- [ ] Регистры = confidence?
- [ ] Напряжение — сильнейший раздел?
- [ ] Сцены с деталями, не описания черт?
- [ ] Нет методик, запрещённых слов?
- [ ] Действия невозможны для другого профиля?
- [ ] Нет лести?
- [ ] Эффект «откуда знаешь», не «красиво написано»?

## Калибровка контента

Задачи E12-04 и E12-05 в `docs/13-roadmap.md`.

- Тексты ветвей ступеней 1–3: ожидается **10–15% переписать** по живым реакциям
- Вопросы с высоким несогласием → перефразировать или заменить
- Узлы с низким узнаванием → проверить пороги в scoring
- Пороги генерации срезов заданы строго и ожидаемо поедут вниз
