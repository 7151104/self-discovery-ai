# 20 концептов: слайды пути + кабинет

Ещё не разработка. Щупаем жест, палитру, форму.

**Два слоя продукта**
- **Слайды** — куски пути: подарок, хук, порция, карта. Свайп в сторону. Можно атмосферу.
- **Кабинет** — дом. Полки. Сюда возвращаешься. Это не отменяется слайдами.

Живое в прототипе: типы **Слайды** и **Кабинет**. На слайдах внизу — 8 кож (дождь / тушь / море / кино / камень / иней / лес / сумерки), свайп пальцем.
