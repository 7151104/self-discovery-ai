# 11. UI-сценарий личной страницы

Продукт — **одна живая страница на домене**, которая заполняется по мере ответов.
Не форма с результатом в конце, не PDF, не чат.

Реализует: Закон 1 (ценность до шага) и требование «карта маршрута видна сразу».

---

## Главный принцип экрана

**Человек всё время находится на своей странице.** Вопросы приходят к нему туда,
а не уводят в отдельный опросник. После каждой порции страница растёт вниз —
он видит, что она стала больше, и это единственная награда, которая нужна.

```
┌──────────────────────────────┐
│  Шапка: имя, тема периода    │  ← ступень 0, не меняется
├──────────────────────────────┤
│  Фраза-крючок (крупно)       │  ← появляется после ступени 1, обновляется на 3 и 4
├──────────────────────────────┤
│  Визуальная карта, 7 полос   │  ← растёт с каждой порцией
├──────────────────────────────┤
│  Блок «Как ты работаешь»     │  ← ступень 1
│  Блок «Как тебя задевает»    │  ← ступень 2
│  Блок «Где ты себе мешаешь»  │  ← ступень 3
│  Блок «Твой сюжет»           │  ← ступень 4
├──────────────────────────────┤
│  Активная порция вопросов    │  ← всегда внизу заполненного, «что дальше»
├──────────────────────────────┤
│  Маршрут: закрытые двери     │  ← виден с самого начала, подписи уточняются
└──────────────────────────────┘
```

---

## Состояния страницы

| Состояние | Что на экране | Что доступно |
|-----------|---------------|--------------|
| `s0` | Шапка + пустая карта + маршрут заглушкой | Порция 1 (3 вопроса) |
| `s1` | + блок 1 + 3 полосы заполнены | Порция 2 (4 вопроса) |
| `s2` | + блок 2 + 5 полос | Порция 3 (4 вопроса) |
| `s3` | + блок 3 (один узел) + 7 полос + первые двери подписаны под профиль | Порция 4 (1 открытый) |
| `s4` | + блок 4 + предложение среза | Оплата |
| `paid_pending` | + доборы среза порциями | Вопросы среза |
| `paid_done` | + блок среза + новые двери | Следующее предложение |

Переход между состояниями — только вперёд. Ответы редактируются, но пересчёт
переписывает блоки (см. «Изменение ответов»).

---

## Анатомия блока

Каждый блок разбора устроен одинаково:

```
┌─────────────────────────────────────┐
│ Как ты работаешь                    │  ← заголовок из content/step*.md
│                                     │
│ [3 абзаца, 80–150 слов]             │  ← lookup-тексты по ответам
│                                     │
│ ── сшивка ──                        │  ← фраза из матрицы пар, если есть
│ [1 абзац, выделен визуально]        │
│                                     │
│ Не согласен с этим  ·  Поделиться   │  ← две действия, мелко
└─────────────────────────────────────┘
```

**«Не согласен с этим»** — обязательный элемент, а не вежливость. По `docs/08-legal-safety.md`
несогласие — это данные: оно понижает confidence координаты и попадает в калибровку текстов.
Клик открывает выбор: «это не про меня» / «частично» / «слишком общо».

Фраза-сшивка визуально сильнее остальных абзацев: она и есть кандидат на скриншот.

## Визуальная карта

**7 полос. Без цифр, без процентов, без названий методик.**

| Полоса | Координата | Левый полюс | Правый полюс | Ключ |
|--------|------------|-------------|--------------|------|
| Темп | 2 | ровный поток | импульсы | `tempo` |
| Доведение | 11 | до конца | обрыв | `completion` |
| Под давлением | 9 | замирание | ускорение | `pressure` |
| Что задевает | 8 | (категория, без оси) | | `trigger` |
| Внимание | 3 | конкретика | связи | `attention` |
| Структура | 5 | определённость | открытый финал | `structure` |
| Удержание | 7 | отпускает | держит долго | `holding` |

Колонка «Координата» — внутренняя: номер координаты наружу не уходит. Клиент опознаёт
полосу ключом из последней колонки, и его движок отдаёт в `MapBar.key`.

Каждая полоса имеет три визуальных состояния:

- **пустая** — данных нет; выглядит как контур. Кликабельна → «это откроется, когда ответишь на…»
- **предположительная** — `confidence: low/medium`; маркер размытый, полоса приглушена
- **точная** — `confidence: high`; маркер чёткий, полоса контрастная

Полоса «Что задевает» — не ось, а помеченная точка из семи возможных, остальные шесть
приглушены. Это единственная категориальная полоса, и она самая цепляющая: человек видит,
что из семи вариантов подсвечен один.

**Правило:** карта никогда не показывает 16 координат. Показывает 7 и честно говорит,
что остальное закрыто. Полная карта — платный продукт, и она видна как отсутствие.

Анимация: при заполнении полосы маркер приезжает из центра за 400–600 мс, один раз,
без повторов при скролле. Пустые полосы не анимируются.

## Закрытые двери и маршрут

Маршрут виден **с первого экрана**, до первого вопроса. Никаких paywall-сюрпризов.

Состояния двери:

| Состояние | Вид | Подпись |
|-----------|-----|---------|
| Закрыта, тема неизвестна | контур, приглушена | общая: «Как ты принимаешь решения» |
| Закрыта, тема известна | контур, читаемая | **под профиль**: «Почему ты останавливаешься у финиша» |
| Открывается ответами | контур + значок вопросов | «Откроется после четырёх вопросов» |
| Открыта | заполнена, ведёт к блоку | заголовок блока |
| Платная, предложена | выделена, одна на экране | оффер + цена |

**Обязательно:** минимум одна дверь открывается бесплатными ответами на каждой ступени.
Это доказательство, что маршрут — не выкачивание. Без этого двери читаются как витрина.

После ступени 3 подписи дверей переписываются под конкретный профиль: не «срез отношений»,
а «Как этот механизм работает в близких». Тексты подписей — в `content/doors.md`: реестр по
узлам (`dominant_node` и вторые сработавшие), реестр прикладных дверей под узел и общие
подписи по срезам для состояния, когда тема человеку ещё не известна.

**На первом шаге оплаты видна одна платная дверь.** Остальные платные — закрыты и без цены.

## Порция вопросов

Порция — не страница опросника, а карточка внизу заполненной части.

```
┌─────────────────────────────────────┐
│ Ещё четыре вопроса                  │
│ и покажу, где ты сам себе мешаешь   │  ← обещание конкретного результата
│                                     │
│ ● ○ ○ ○                             │  ← прогресс внутри порции
│                                     │
│ Что задевает тебя сильнее всего?    │
│                                     │
│ ( ) когда меня не воспринимают…     │  ← варианты полным текстом
│ ( ) когда я теряю контроль…         │
│ …                                   │
└─────────────────────────────────────┘
```

Правила:

- **Один вопрос на экране.** Не список из четырёх.
- Выбор варианта = переход к следующему. Кнопки «Далее» нет для типа `выбор`.
- Шкала: 5 отметок с подписями полюсов, без чисел в интерфейсе.
- Назад — можно, всегда.
- Прогресс показывается **внутри порции** (1 из 4), никогда «вопрос 8 из 12»:
  общее число вопросов не заявляется, потому что лестница не тест.
- После последнего вопроса порции — короткая пауза (600–900 мс) с текстом «собираю»,
  затем страница прокручивается к новому блоку. Пауза нужна: мгновенный ответ
  обесценивает результат, длинная имитация раздражает.

Открытый вопрос (L12): поле на 5–6 строк, счётчик слов появляется после 5 слов,
кнопка активна от 15 слов. Подсказка не исчезает при фокусе.

## Точка оплаты (после ступени 4)

Экран после блока «Твой сюжет» — **одно предложение, ничего больше**.

```
┌─────────────────────────────────────┐
│ [Имя], я вижу, откуда замыкается    │
│ этот круг — но не откуда он пошёл.  │
│                                     │
│ Чтобы разобрать, где механизм       │
│ включился впервые и что с ним       │
│ делать, мне нужно ещё 10 вопросов   │
│ про твои остановки.                 │
│                                     │
│ [ Открыть — 590 ₽ ]                 │
│                                     │
│ Что внутри: механизм · когда        │
│ включился · три действия под тебя   │  ← состав, не список выгод
│                                     │
│ Не сейчас — страница останется      │  ← выход без давления
└─────────────────────────────────────┘
```

На экране показан `slice_node_finish`: 10 вопросов, 590 ₽. Число вопросов, цена и тема —
не литералы, а подстановки из `content/slices/README.md`; шаблон предложения живёт в
`content/step4-open-synthesis.md`, значения отдаёт `engine/src/offers.ts`.

Состав («что внутри») и текст отказа у каждого среза свои: они живут в его файле
(`content/slices/*.md`, раздел «Экран оплаты»), доступ — `engine/src/pay-screens.ts`.
Обещание на экране — то же, что в оффере среза, вторым текстом оно не переписывается.
Цена на экране одна: в реестре микрокопии она стоит только в `UI_PAY_BUTTON`.

Запрещено на этом экране: таймеры, счётчики мест, зачёркнутые цены, «осталось 3 часа»,
вторая кнопка с другим продуктом, отзывы, звёзды.

После оплаты — **сразу вопросы, а не отчёт**. Это физическое подтверждение Закона 2:
новые ответы для нового среза. Экран ожидания генерации показывает, какие координаты
уточняются, без имитации «ИИ думает».

## Микрокопия (тон)

Тексты интерфейса целиком живут в `content/ui-copy.md`: каждая строка имеет идентификатор,
компоненты принимают текст параметром, в коде и в разметке русских строк нет. Таблица ниже —
примеры тона, а не источник правды.

| Место | Текст |
|-------|-------|
| Вход | «Три вопроса — и я скажу, как ты на самом деле работаешь» |
| Между порциями | «Ещё четыре — и покажу, где ты сам себе мешаешь» |
| Пропуск даты | «Без даты — без карточки периода. На разбор это не влияет» |
| Кнопка отказа | «Не сейчас — страница останется» |
| Несогласие | «Это данные, а не жалоба. Учту» |
| Пустая полоса | «Откроется, когда ответишь на вопросы про решения» |

Обращение — на «ты», везде. Мы не говорим «пройдите тест», «ваш результат», «поздравляем».

## Виральность

Скриншотится **фраза-крючок и карта**, не отчёт целиком. Значит:

1. Фраза-крючок — отдельный экранный блок с воздухом, читается без контекста.
2. Карта помещается на один экран телефона целиком.
3. Кнопка «Поделиться» отдаёт **картинку** (крючок + карта + домен), не ссылку на тест.
4. Ссылка ведёт на **его** страницу в режиме просмотра: другой человек видит карту и одну
   фразу, но не разбор целиком. Внизу — «сделать свою», без слова «тест».
5. Приватность по умолчанию: страница не публична, пока человек не нажал «Поделиться».
   Публичный вид скрывает блоки 3 и 4 (узел и сюжет) — там слишком личное.

## Краевые состояния

| Ситуация | Поведение |
|----------|-----------|
| Дата не введена | Шапка без темы периода, всё остальное работает |
| Ответ L12 короче 15 слов | Кнопка неактивна, подсказка: «Пары предложений мало — опиши, как оно обычно идёт» |
| Кризисные признаки в L12 | Блок 4 не генерируется. Вместо него — текст поддержки и контакты (`docs/08-legal-safety.md`). Оффер не показывается вообще |
| Ни один узел не сработал | Блок 3 = честный текст `NODE_NONE` из `content/step3-contradictions.md`: противоречия не набралось, и это само по себе редкость. Узел не выдумывается и не подставляется по умолчанию |
| Человек ушёл на середине | Страница сохраняется по ссылке. Возврат — на ту же порцию. Никаких «вы не завершили» |
| Отказ от оплаты | Страница остаётся полной, двери остаются, повторного оффера в тот же визит нет |
| Изменение ответа | Пересчёт профиля и перезапись блоков с пометкой «обновилось»; купленные блоки не переписываются, к ним добавляется отметка о расхождении |
| Оплата не прошла | Дверь остаётся закрытой, страница не меняется, текст говорит, что деньги не списаны. Повторной попытки на экране не навязываем |
| Текст среза не собрался | Ответы сохранены, блок не появляется, деньги возвращаются полностью: пока итогового текста нет, услуга не оказана (`content/legal/offer.md`, пункт 6) |

Тексты всех девяти состояний — в `content/ui-copy.md`, группа `EDGE`; кризисное состояние
берёт полный текст и контакты из `content/crisis.md`.

## Мобильный приоритет

Основной сценарий — телефон, вертикально, одной рукой.

- Все интерактивные цели ≥ 44 px.
- Порция вопросов помещается на экран без скролла.
- Карта — во всю ширину, полосы горизонтальные.
- Текст блока — 16–18 px, длина строки ≤ 40 знаков.
- Никаких модальных окон на пути прохождения.

---

## Что не делаем (проверочный список для дизайнера)

- Не показываем общее число вопросов
- Не показываем проценты, баллы, «твой тип — …»
- Не называем методик ни в интерфейсе, ни в подписях
- Не делаем витрину продуктов на первом шаге оплаты
- Не используем таймеры и искусственный дефицит
- Не имитируем «ИИ печатает» на ступенях 1–3 — там готовые тексты, они мгновенные
- Не поздравляем с прохождением
- Не просим оценить сервис до того, как человек получил разбор

## Технические требования к фронту

- Страница — по постоянной ссылке `/p/{profile_id}`, без обязательной регистрации.
- Состояние (ответы + профиль) сохраняется на сервере после каждой порции; локально —
  только черновик текущего ответа.
- Ступени 1–3 рендерятся из lookup-контента: сетевого запроса к LLM нет, задержки нет.
- Ступень 4 и платные срезы — асинхронная генерация со стабильным состоянием ожидания.
- Профиль наружу не отдаётся: клиент получает готовые блоки и состояния полос,
  а не значения координат. Значения координат — серверная тайна продукта.
- Печать и сохранение в PDF допустимы, но не являются продуктом.

Реализация прототипа: `engine/` (движок и контент) + `prototype/` (кликабельная страница).
