# 10. Бизнес-контекст

## Роль основателя

- **Разработчик**, не лицо бренда
- Не ведёт соцсети, не светится
- Сильные стороны: продукт, система, код, архитектура
- Слабая сторона (осознанная): личный маркетинг

## Каналы роста (в порядке приоритета)

### 1. Виральный артефакт
- Личная страница + визуальная карта + фраза-крючок
- Человек пересылает ссылку, не «пройди тест»
- Продукт = рекламный материал

### 2. Партнёры с аудиторией
- Психологи, коучи, астрологи, инфобизнес — косвенные конкуренты и лучший канал
- Заход: бесплатный разбор их клиента → «можно так для всех?»
- Не презентации, а готовый результат в руках

### 3. B2B white-label
- Инструмент для практиков под их брендом
- Основатель невидим
- Регулярная подписка, не разовые чеки
- Экономика лучше розницы

### 4. Платная реклама
- **Добавка**, не двигатель
- CAC часто > первого чека
- Работает только с LTV (маршрут + подписка)

## Конкуренты (косвенные)

- Отдельные тесты (MBTI-сайты, 16personalities)
- Эзотерические сервисы (натальные карты, HD)
- Психологи и коучи в соцсетях
- ChatGPT «расскажи про меня»

**Наш зазор:** согласованный мульти-модельный разбор + маршрут + накопление на русском.

## Почему не «сделаю продукт и залью рекламу»

В нише self-discovery платный трафик без LTV и виральности не окупается.  
Выживают: бесплатный/дешёвый трафик + повторные покупки.

## Риски для основателя-разработчика

| Риск | Описание |
|------|----------|
| Over-engineering UI | 20 виджетов вместо одной фразы и одного визуала |
| Пропуск валидации | Код до живых людей |
| Зависимость от LLM-магии | Без правил = вода |
| Ожидание продажи бизнеса | Это cashflow-бизнес, не exit |

## Решения, которые основатель уже принял

- Русский рынок первым
- Не лицо компании
- Маршрут отчётов, не один продукт
- Символика есть, но не утверждает
- Сопровождение как терапия — нет; направления и приёмы — да
- IP: переименовывать при необходимости, результат важнее происхождения

## Что основатель сомневался (и как решили)

| Сомнение | Решение |
|----------|---------|
| Тяжёлый вход убьёт конверсию | Лестница порциями |
| Дата рождения vs вопросы | Дата = вход; выводы = вопросы |
| Смогу ли дотянуть маркетинг | Виральность + партнёры + B2B, не личный блог |
| Реально ли заработать | Да, при LTV; нет при одном чеке и платном трафике |
| Насколько крутой UI нужен | Одна фраза + один визуал > дашборд |

движок координат и кликабельный прототип ступеней 0–4 (`engine/`, `prototype/`).
