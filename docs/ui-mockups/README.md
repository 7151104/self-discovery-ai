# UI-концепты: 10 экранов

Концепт-арт интерфейса, сгенерированный как визуальный якорь перед прототипом.  
Рабочее имя бренда в макетах — **координаты**. Это не утверждённое имя продукта.

## Система

- Фон: тёплый почти-чёрный, зерно
- Текст: кремовый
- Акцент: медь / терракота
- Крупные хуки — антиква; UI — гротеск
- Наружу не выходят MBTI, знаки зодиака, проценты, витрина продуктов

## Что брать в прототип

1. Хук крупнее имени — страница должна читаться со скриншота.
2. Карта — полосы пигмента, не радар и не проценты.
3. После бесплатного — **одна** дверь, остальные видны как маршрут.
4. Дата рождения даёт визуал карточки, не характер.

## Не копировать буквально

Это картинки, не продакшен-макет. Кириллица в генерации может плыть. Иконки-звёзды и 3D-двери — атмосфера, не спецификация. Канон — `docs/05-user-journey.md` и `docs/06-report-structure.md`.
