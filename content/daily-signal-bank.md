# Банк ежедневных Сигналов

Lookup only. Не LLM на ежедневной линзе.  
Правила продукта: `docs/11-daily-ritual-and-social.md`.  
Качество текста — как ветви ступеней 1–3 и узлы `content/step3-contradictions.md`.

Один Сигнал = `lens` + `micro` + `share_line` + `offer_hook`.  
Ротация выбирает строку банка, не пишет новую личность.

---

## Как выбирать строку

Вход: `dominant_node`, набор координат с band ≥ medium, последние 7 `signal_id`, последние ответы микро.

1. Отфильтровать строки, чьи `requires` выполнены.
2. Снять `signal_id`, которые были в последние 2 дня (сцена) / 3 дня (координата).
3. Снять строки, по которым два «мимо» подряд.
4. Взвесить: узел 0.4 / координата 0.35 / цена силы 0.15 / пауза 0.1 — и не ставить узел два дня подряд.
5. День 1 после лестницы: принудительно первая строка главного узла, сцена `SHOW`.

Если человек нажал контекст дня — сначала фильтр по `scene`.

---

## Сцены

| id | Когда всплывает в жизни |
|----|-------------------------|
| SHOW | Надо показать почти готовое |
| CRIT | Оценка, замечание, «не серьёзно» |
| START | Вход в своё дело без внешнего пинка |
| DEADLINE | Чужой срок, ждут снаружи |
| RUMINATE | Вечер, прокручивание разговора |
| NEW | Новая возможность, оффер, идея |
| LOAD | Давление, объём, «всё на себе» |
| DETAIL | Мелочи, которые «подождут» |
| PAUSE | Пауза, восстановление, ничего не доказывать |
| OPEN | Незакрытое решение, висящий контур |

---

## Типы микро

| type | Формат ответа | Данные в профиль |
|------|---------------|------------------|
| OBSERVE | было / не было / мимо | подтверждение или снижение confidence узла/координаты |
| TINY | сделал / не дошёл / не тот день | флаг `tried_intervention` + тот же узел |
| CONTEXT | (опционально утром) показ / критика / дедлайн / тихо | только выбор сцены, не черта |

---

## Поля строки

- `id` — стабильный
- `node` / `coords` — якоря
- `scene`
- `family` — node / coord / cost / pause
- `confidence_min` — high | medium
- `lens` — 3–5 предложений, проверяемых
- `sign` — признак «это оно»
- `micro` — одно действие или вопрос
- `micro_type`
- `share_line` — одна фраза для карточки, без уязвимости в сыром виде
- `offer_hook` — кусок для оффера, если эту линзу подтвердили
- `forbidden` — чего эта строка не должна скатываться

## NODE_FINISH_FEAR

Требование: узел финиша / coord 11 рвётся на показе.

### SIG_FINISH_SHOW_01  · день 1 · node · SHOW

**lens:** Сегодня, когда работа почти готова, ты скорее начнёшь её править, чем покажешь. Пока не показано — оценки не существует, и это сейчас работает как защита, не как качество.  
**sign:** Уже «можно отдать», а рука идёт в мелкие правки.  
**micro_type:** OBSERVE  
**micro:** До конца дня: правки после «готово» были, показа не было — да / нет / мимо.  
**share_line:** Я довожу до 80% идеально. Последние 20% у меня про оценку, не про работу.  
**offer_hook:** ломается на показе, не на работе  
**forbidden:** не называть ленью; не советовать «просто покажи» как универсальный лайфхак в линзе (это микро, и только в TINY-днях)

### SIG_FINISH_SHOW_02  · node · SHOW · TINY

**lens:** Сегодня у финиша будет развилка: ещё один круг правок или показ в текущем виде. Второй вариант для тебя ощущается как выход без брони.  
**sign:** Мысль «ещё чуть-чуть и будет можно».  
**micro_type:** TINY  
**micro:** До 16:00 показать черновик одному человеку. После решения показать — ни одной правки. Сделал / не дошёл / не тот день.  
**share_line:** Мой финиш ломается не от усталости. Он ломается, когда следующим шагом идёт показ.  
**offer_hook:** остановка на выходе к людям

### SIG_FINISH_CRIT_01  · node · CRIT

**lens:** Если сегодня прилетит оценка «недостаточно серьёзно» или просто молчание — ты, скорее всего, уйдёшь дорабатывать в одиночку, а не уточнять, что именно не так. Так оценка остаётся невидимой и бесконечной.  
**sign:** После замечания vis-à-vis нет, правок — много.  
**micro_type:** OBSERVE  
**micro:** Сегодня оценка задела и ушла в скрытую доработку — да / нет / мимо.  
**share_line:** Я лучше переделаю втихую, чем уточню, что не так. Так безопаснее. И так никогда не кончается.  
**offer_hook:** оценка запускает доработку вместо разговора

### SIG_FINISH_RUMINATE_01  · node · RUMINATE

**lens:** Вечером почти готовое дело, скорее всего, прокрутится как «ещё не то». Это не план на завтра. Это репетиция оценки, которой ещё не было.  
**sign:** В голове правки, в календаре — нет слота «показать».  
**micro_type:** OBSERVE  
**micro:** Перед сном: прокручивал финиш как угрозу, а не как следующий шаг — да / нет / мимо.  
**share_line:** Я репетирую оценку ночью. Днём из-за этого не отдаю работу.  
**offer_hook:** прокручивание подменяет финиш

## NODE_PLAN_VS_OPEN

### SIG_PLAN_OPEN_01  · node · OPEN

**lens:** Сегодня ты, скорее всего, оставишь важное незакрытым и назовёшь это гибкостью. Тебе тяжело от открытого контура — и ты сам его держишь, потому что закрыть = обязаться.  
**sign:** Есть все данные решить, решения нет, в теле гул.  
**micro_type:** OBSERVE  
**micro:** Сегодня держал незакрытым то, что уже можно было закрыть — да / нет / мимо.  
**share_line:** Я называю это свободой. На деле это отсутствие обязательства — и фоновый гул, который я принял за норму.  
**offer_hook:** открытый контур как защита от обязательства

### SIG_PLAN_OPEN_02  · node · OPEN · TINY

**lens:** Сегодняшняя цена открытого финала — не свобода, а фоновый шум. Один закрытый контур тише, чем три «ещё подумаю».  
**sign:** Переключаешься между незакрытыми, ни одно не двигается.  
**micro_type:** TINY  
**micro:** Выбери один висящий вопрос. Закрой его сегодня фразой «решение такое: …» себе в заметку. Даже временное. Сделал / не дошёл / не тот день.  
**share_line:** Мне нужен план — и я сам оставляю финал открытым. Плачу шумом, не свободой.  
**offer_hook:** решение как обязательство, не как логика

## NODE_EXTERNAL_DEADLINE

### SIG_EXT_DEADLINE_01  · node · DEADLINE

**lens:** Сегодня ты, скорее всего, сдвинешься там, где тебя ждут, и провисшь там, где срок только твой. Воли на своё хватает ненадолго — это не характер, это устройство входа.  
**sign:** Чужие задачи закрыты, своё «ещё успею».  
**micro_type:** OBSERVE  
**micro:** Своё без внешнего срока сегодня стояло, чужое ехало — да / нет / мимо.  
**share_line:** Я отлично двигаюсь, когда меня ждут. В своих делах такого ожидания нет — и я это чувствую.  
**offer_hook:** без внешнего срока вход не включается

### SIG_EXT_START_01  · node · START · TINY

**lens:** На своё дело сегодня не хватит «решу и сделаю». Нужна внешняя точка, даже искусственная.  
**sign:** Открыл своё — и ушёл в чужой чат, где тебя уже ждут.  
**micro_type:** TINY  
**micro:** Назначь одному человеку время, когда покажешь кусок своего. 20 минут. Сделал / не дошёл / не тот день.  
**share_line:** Мне не нужна мотивация. Мне нужна дверь, в которую меня ждут.  
**offer_hook:** вход через чужое ожидание

## NODE_OVERLOAD

### SIG_OVER_LOAD_01  · node · LOAD

**lens:** Под давлением сегодня ты, скорее всего, заберёшь ещё объём, а не снимешь. Клапана нет: ни вынести, ни отдать. Держишь до предела.  
**sign:** После «мне тяжело» в списке дел плюс, не минус.  
**micro_type:** OBSERVE  
**micro:** Сегодня добавил себе работы в момент, когда уже было много — да / нет / мимо.  
**share_line:** Когда правильно снять половину, я добавляю объём. Потом выпадаю целиком.  
**offer_hook:** нагрузка без клапана

### SIG_OVER_PAUSE_01  · pause · PAUSE · TINY

**lens:** Сегодня полезнее не подвиг, а клапан. Ты восстанавливаешься медленнее, чем тратишь — ещё один рывок без снятия объёма завтра обойдётся провалом.  
**sign:** Хочется «ещё чуть-чуть дожать», тело уже нет.  
**micro_type:** TINY  
**micro:** Сними с сегодня одну задачу, которую взял по инерции. Напиши кому-то «это подождёт». Сделал / не дошёл / не тот день.  
**share_line:** Я включаюсь на полную и плачу провалом после рывка. Клапан — часть работы, не слабость.  
**offer_hook:** расход без восстановления

## NODE_CRITICISM_INTERNAL

### SIG_CRIT_01  · node · CRIT

**lens:** Если сегодня заденет, снаружи, скорее всего, будет тихо. Ты не защищаешься в моменте — и платишь один, несколько часов или дней. Со стороны «не задело». Это не так.  
**sign:** Кивнул, ушёл, прокручиваешь формулировку.  
**micro_type:** OBSERVE  
**micro:** Задело и ушло внутрь без фразы наружу — да / нет / мимо.  
**share_line:** Со стороны кажется, что меня не задело. Поэтому ситуация может повторяться.  
**offer_hook:** удар уходит в молчаливое прокручивание

### SIG_CRIT_RUMINATE_01  · node · RUMINATE

**lens:** Вечернее прокручивание сегодня, скорее всего, будет доигрывать дневной разговор, на который в моменте не было ответа. Это не анализ. Это запоздалая защита.  
**sign:** Переписываешь диалог, который уже кончился.  
**micro_type:** OBSERVE  
**micro:** Крутил сегодняшний разговор после факта — да / нет / мимо.  
**share_line:** Я отвечаю на критику с задержкой в несколько часов. В комнате меня уже нет.  
**offer_hook:** отложенная реакция вместо ответа в моменте

## NODE_POTENTIAL_VS_DETAIL

### SIG_POT_DETAIL_01  · node · DETAIL

**lens:** Сегодня дело, скорее всего, споткнётся не о видение, а о мелочь, которую ты уже пометил как «потом». Тебя раздражает, когда тормозят деталями. Дела умирают именно там.  
**sign:** Большой ход ясен, маленький шаг не сделан.  
**micro_type:** OBSERVE  
**micro:** Сегодня видение было, конкретика подождала — да / нет / мимо.  
**share_line:** Я вижу, куда это вырастет. Умирает не видение — деталь, которая мне кажется мелкой.  
**offer_hook:** провал на конкретном шаге, не на смысле

### SIG_POT_NEW_01  · coord · NEW

**lens:** Новое сегодня включит тебя картиной «что из этого выйдет». Как оно устроено — второй вопрос, и до него можно не дойти.  
**sign:** Уже рассказываешь возможность, ещё не открыл, как она работает.  
**micro_type:** OBSERVE  
**micro:** Сегодня зажёгся возможным, не проверяемым — да / нет / мимо.  
**share_line:** Меня занимает, что из этого может выйти, а не как оно устроено.  
**offer_hook:** вход через возможность, зависание на устройстве

## Координаты без узла (когда узел не ставим второй день)

Использовать только при band ≥ medium. Тексты — каркас: в продукте подставляется значение координаты из профиля, не общий абзац. Ниже — эталон для демо-профиля и шаблон подстановки.

### Шаблон COORD_GENERIC

```
Сегодня, скорее всего, включится {coord_value} — в сцене {scene_human}.
Признак: {falsifiable_sign}.
Если признака не было — это не «ты другой человек». Это данные: сегодня сцена не встретилась или координата слабее, чем кажется.
```

### SIG_C11_START_01  · coord 11 · START

**lens:** Связка «решил — сделал» сегодня, скорее всего, рванётся не на старте, а когда дело надо вынести из головы в чужие руки. Начало ты умеешь.  
**sign:** Своё открыто, никому не сказано, что оно существует.  
**micro_type:** OBSERVE  
**micro:** Сегодня было «уже делаю», не было «уже видно снаружи» — да / нет / мимо.  
**share_line:** Я не ленивый. Я невидимый на последней четверти.  
**offer_hook:** доведение рвётся на выходе

### SIG_C7_RUMINATE_01  · coord 7 · RUMINATE

**lens:** Один неприятный момент сегодня может забрать остаток дня. Это не «слишком чувствительный». Это скорость и длительность задевания — так устроена реакция.  
**sign:** Событие короткое, хвост длинный.  
**micro_type:** OBSERVE  
**micro:** Задевание длилось дольше ситуации — да / нет / мимо.  
**share_line:** Меня задевает надолго. Короткий разговор может забрать вечер.  
**offer_hook:** реактивность с длинным хвостом

### SIG_C2_PAUSE_01  · cost / pause · PAUSE

**lens:** Ты включаешься импульсом и тратишься быстрее, чем восстанавливаешься. Сегодняшняя «ещё одна задача» с высокой вероятностью оплачена завтрашним провалом.  
**sign:** После рывка нет паузы в календаре, только следующая.  
**micro_type:** TINY  
**micro:** Поставь в календарь 40 минут без входа. Не заслуга — гигиена ритма. Сделал / не дошёл / не тот день.  
**share_line:** Я не ровный поток. Я импульс с обязательным провалом после, если нет клапана.  
**offer_hook:** ритм расхода без восстановления

## Цена силы (Правило 6)

Всегда пара из той же координаты. Без этого ежедневный слой становится либо лестью, либо долбёжкой слабости.

### SIG_COST_FINISH_01  · cost · SHOW

**lens:** Твоя сила — не бросать на середине смысла. Сегодняшняя цена этой силы — бесконечная доработка вместо выхода. Качество настоящее. Финиш из-за него же откладывается.  
**sign:** Улучшаешь уже хорошее, потому что «ещё не достойно».  
**micro_type:** OBSERVE  
**micro:** Сегодня сила (дожать качество) съела финиш — да / нет / мимо.  
**share_line:** Моя сила — не выпускать сырое. Цена этой силы — не выпускать вообще.  
**offer_hook:** сила и тормоз из одной координаты

## Пауза / «чего не делать»

Без этих дней ритуал = давление. 10% ротации.

### SIG_PAUSE_GENERIC_01  · pause · PAUSE

**lens:** Сегодня не день, чтобы чинить устройство. День, чтобы заметить его на холостом ходу: где включаешься сам, где тебя ждут, где уже хватит.  
**sign:** Нет кризиса. Есть соблазн изобрести задачу, чтобы не сидеть с собой.  
**micro_type:** OBSERVE  
**micro:** Сегодня ничего не чинил и не геройствовал — да / нет / мимо.  
**share_line:** Иногда самопознание — это не вывод. Это день без автопилота подвига.  
**offer_hook:** (оффер в паузу не ставить)

## Недельная сводка (каркас, сюда уже можно LLM)

Вход: 7 пар (signal_id × ответ микро).  
Выход: 120–180 слов.

```
На этой неделе ты открыл страницу {n} из 7.
Узел «{node_human}» подтвердился {k} из {m}.
Самый частый признак: {sign}.
Где было «мимо»: {ids} — это не отмена профиля, это границы сцены.

Чего я по этим семи дням всё ещё не знаю: {gap → дверь среза}.
```

Оффер — одна дверь, селектор как в `docs/07-monetization-route.md`, но первая строка = факты недели.

## Анти-Barnum для банка

Строку выкинуть, если:

- подходит человеку с другим узлом без правки,
- нет признака, по которому нажмут «мимо»,
- есть событие/срок,
- есть запрещённые слова из bootstrap,
- share_line стыдит или ставит диагноз,
- микро длиннее 90 секунд или требует эссе.

Калибровка: 10–15% строк банка переписать по живым «мимо», как ветви ступеней 1–3.

## Что ещё дописать (не блокирует фазу A)

- Полный набор строк на все 16 координат × 10 сцен (сейчас закрыты узлы лестницы + демо-координаты).
- Строки после платных срезов (работа, близость, деньги) — когда будут доборы.
- Локализации сцен под B2B-практика (он выбирает тон, якоря те же).
