# Каркас личной страницы — что реально рисуем

Это не постер и не «настроение». Это экран приложения. Порядок блоков зафиксирован продуктом. Менять можно только кожу (цвет, шрифт, плотность), не состав и не смысл.

## Что страница умеет

Живая страница на домене, не PDF. Накапливается по ступеням. Часть дверей открывается ответами, часть — деньгами. Карта маршрута видна сразу.

## Слои (сверху вниз, мобильная колонка)

| # | Блок | Откуда | Зачем |
|---|------|--------|-------|
| 1 | Шапка: бренд, шаринг, копирование ссылки `…/имя` | продукт | виральность, не «пройди тест» |
| 2 | Имя крупно, дата мелко | ступень 0 | узнавание «это моё» |
| 3 | Фраза-крючок, 1–2 строки | матрица L1×L2 / узел | скриншот |
| 4 | Прогресс лестницы: ступень X из 4, сколько вопросов | UX | не сюрприз, не 35 вопросов |
| 5 | Карта 6–8 полос без % | 16 координат, сжато | скриншот №2 |
| 6 | «Как ты работаешь» | ступень 1, lookup | узнавание |
| 7 | «Как обрабатываешь и как тебя задевает» | ступень 2, lookup | механизм + цена силы |
| 8 | «Где ты сам себе мешаешь» — один узел, без совета | ступень 3, движок | зуд |
| 9 | «Твой повторяющийся сюжет» + обрыв | ступень 4, LLM | её слова, без выхода |
| 10 | Маршрут / двери под ЭТОТ профиль | монетизация | одно первое предложение видно, остальные не прячем |
| 11 | Одна кнопка: «ещё N вопросов» или «разобрать узел 590 ₽» | законы 1–2 | ценность уже выдана |
| 12 | Низ: Я / дальше / карта / ещё | мобильный возврат | завтра есть куда зайти |

Пока ступень не пройдена — блок на месте, но закрыт короткой подписью («ещё 4 вопроса»), не пустым местом и не декоративным замком без смысла.

## Двери (подписи только от профиля)

После узла «финиш / оценка» например:

- Почему ты останавливаешься у финиша → 590 ₽ (первое)
- Как этот механизм в близких
- Как тебе принимать решения
- Полная карта

Не витрина из пакетов на входе. Не «тарифы». Не проценты совместимости.

## Чего на этом экране нет

- Плакат на весь экран без блоков
- Типы, MBTI, знаки, чакры, «энергия»
- Радар, %, «87% match»
- Четыре цены сразу
- Лицо основателя
- Слова «пройдите тест»

## Экраны рядом со страницей (тоже продукт, не арт)

1. Вход: имя + дата → карточка периода (0 выводов о характере)
2. Порция вопросов 3–4, прогресс ступени
3. Страница (этот каркас)
4. Карта крупно (те же 8 полос)
5. Одно предложение 590 ₽ + 8 новых вопросов среза
6. Платный разбор: портрет → напряжение → сцены → цена силы → что делать → опора → чего не знаю
