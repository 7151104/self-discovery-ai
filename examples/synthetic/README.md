# Синтетические профили лестницы

Пять наборов ответов L1–L12. Нужны, чтобы движок на разных людях давал
**пять разных главных узлов**, а не один демо-профиль, размноженный именем.

Это не эталоны сгенерированных отчётов и не ручная приёмка текстов
(`docs/09-validation.md`). Тексты разбора по ним не пишутся, пока нет живого
прогона: иначе калибровали бы выдумку. Проверка — `engine/src/synthetic-profiles.test.ts`:
файлы разбираются, узлы различны.

Формат одного файла:

- строка `**Узел:** NODE_…` — ожидаемый `dominantNode`;
- таблица лестницы L1–L12.

Открытый L12 достаточно длинный и не кризисный: на узел он не влияет.
